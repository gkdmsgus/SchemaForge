SchemaForge 진행상황 (2026-10-28 기준)

완료한 것

  • 회로 설명 → 넷리스트 → 회로도 → 2층 PCB → KiCad DRC → 거버 파일까지 만드는 전체 기능
  • 회로 동작 검사: 전원, LED, 릴레이, 트랜지스터, 555, 레귤레이터를 데이터시트 수치로 판정
  • 회로 오류 자동 수정: AI가 고친 회로를 다시 실행해 오류가 줄 때만 반영
  • 화면 기능: 3D 기판에서 부품 배치 체크, 부품 방향(극성) 표시, 부품표(BOM), Code 탭, 경고별 해결 버튼
  • 공개 배포 전 보안 보완: 로그인 없이 코드 실행·AI 호출·서버 파일 다운로드가 되던 경로 차단
  • 실제 배포 완료: https://schemaforge-zuco.onrender.com (Render 무료 서버)
  • 배포 주소에서 데모 → PCB → 3D → 거버 내려받기 시험 통과, 데모 기판 5개 DRC 오류 0
  • 자동 검사 375항목 통과, 기판 8개 × 19항목 검사 통과
  • 짧은 주소 연결: https://schemaforge.kro.kr
